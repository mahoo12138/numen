# Numen 文档站设计约定

用户确认的方向是**浅色技术编辑风**：清晰的大标题、能理解流程的交互示意、蓝色强调，并支持深色主题。设计参考 `ui-ux-pro-max` 的文档型落地页、Vue 和无障碍指南，结合 Numen 已有的插件优先定位。

## 信息结构

- 首页先说明用途，再用真实 Capability 展示事件如何流向查询与动作；随后提供产品基础、集成目录和快速开始。
- 文档按“开始使用 / 官方集成 / 扩展 Numen / 参考”组织。使用 VitePress 原生搜索、导航、侧栏、页内目录与上/下篇导航。
- 首页明确标注“交互示意”，不显示虚构执行统计、用户背书或未实现的插件。
- 主按钮引导开始使用，次按钮进入官方集成。首次流程为无需外部账号的 Cron → Echo。

## 视觉规则

| 元素 | 约定 |
| --- | --- |
| 背景 | 浅色 `#fcfcfd`，深色 `#121720`；用细边框划分区域 |
| 强调 | 浅色 `#3451d1`，深色 `#a3b1ff`；用于链接、选中和主要操作 |
| 正文 | 系统中文无衬线字体；代码使用系统等宽字体，不依赖远程字体服务 |
| 排版 | 标题紧凑，正文有足够行距；自定义字号采用 `rem`，行高使用无单位值 |
| 布局 | 首页最大宽度 1248px；桌面双栏首屏，文档阅读区沿用 VitePress |
| 图标 | 统一线性 SVG，装饰图标隐藏于辅助技术，按钮有文本或可访问名称 |
| 动效 | 只保留短暂颜色过渡；不自动播放流程，不做滚动劫持 |

蓝色用于操作与选择，而不是把所有内容装进高对比卡片。集成列表、产品说明采用平面分区，让文档内容保持主导。

## 交互与适配

- 820px 以下首屏切为单栏；560px 以下集成目录与起步区域切为单栏。375px 为手机验收宽度，844 × 390 覆盖横屏。
- 示例流程采用可用方向键、Home、End 操作的 tablist；节点和筛选按钮提供选中状态，预览更新通过礼貌通知区域表达。
- 点击后真实复制启动命令；拒绝剪贴板访问时提供手动复制说明，且下方命令始终可选择。
- 可见焦点、语义化主区域和标题层级必须保留。不能依赖 hover 才能访问信息。
- `prefers-reduced-motion` 关闭动画与过渡；深色主题由 VitePress 管理并持久化。
- 200% 文字放大时实际字号应翻倍，内容不能覆盖或横向溢出；代码块可局部滚动，不能撑宽整个页面。

## 维护与验收

主题变量维护在 `.vitepress/theme/style.css`；图标集中在 `SiteIcon.vue`，首页交互集中在 `LandingPage.vue`。优先使用默认主题能力，避免再造文档壳层。

改视觉后运行 `pnpm docs:test`，查看桌面、手机、深色和文字放大的真实截图。断言通过不能替代人工查看布局；也不能通过隐藏溢出掩盖内容被裁切的问题。涉及链接时补测 `DOCS_BASE=/numen/ pnpm docs:test`。
