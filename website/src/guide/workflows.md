# 编排与运行

从一个小流程开始，先确认节点输入输出，再接入真正的事件源。Workbench 把编辑、测试和正式订阅分开，方便你修改草稿时保留正在使用的版本。

## 编辑草稿

1. 创建 Automation，在编辑器中添加 Trigger、Capability 或控制节点。
2. 选中节点，在 Inspector 中填写参数，并为需要的槽位绑定兼容 Connection。
3. 从上游选择字段引用，连接输入输出。引用路径中的节点 ID 以 Inspector 展示的 Source ID 为准。
4. 在“设置”中声明流程输入，并按需配置[并发控制](./concurrency.md)。
5. 等待自动保存完成，检查发布问题。出现保存冲突时，先比较并选择恢复方式。

参数表单来自能力的 Schema。需要动态值时选择 Reference；需要组合对象或数组时使用对应的表达式编辑器。数组仍是普通值，需要逐项执行时使用 ForEach。

未完成或无效的本地字段会被保留，不会被静默替换成旧值。发布或试运行前先应用、修正这些输入。

## 选择测试范围

| 方式 | 执行内容 | 适合什么情况 |
| --- | --- | --- |
| 草稿试运行 | 当前已保存草稿的固定测试快照 | 检查尚未发布的修改。 |
| 发布版本试运行 | 显式选择的已发布 Revision | 复现历史版本或检查即将激活的版本。 |
| 局部测试 | 编辑器选定范围；按表单提供所需输入或上游样本 | 单独核对节点映射和输出。 |

局部测试当前支持根图中的普通 Capability，可选择“只执行当前节点”或“执行至当前节点”；暂不支持条件、汇合和循环作用域。运行前先预览真实调用与样例替代的范围。

草稿试运行前会保存合法修改，并固定表单显示的草稿版本。之后修改草稿，需要显式保存并重新加载参数。发布版本试运行不需要先激活该版本。

测试不会更换 Active Revision，也不会创建草稿 Trigger 监听。若要测试 Trigger 数据驱动的下游节点，在测试表单中提供对应数据；若要验证真实订阅，仍需发布、激活并启用。

::: warning 测试会执行真实能力
试运行也是持久化 Run，可能发送邮件、发起 HTTP 请求或发布 MQTT 消息。测试使用独立的并发名额，与正式运行隔离；这种隔离不等于外部服务沙箱。连接和数据应选用适合测试的目标。
:::

## 发布并启用

1. **发布：** 校验当前草稿，生成带编号的固定 Revision。
2. **激活：** 在已发布版本列表中选择用于接收新事件的版本。
3. **启用：** 开启 Automation，等待 Trigger 及所需 Connection 可用。

发布新版本不会自动把正在执行的 Run 切过去。切换激活版本影响后续订阅；旧 Run 继续使用接受时的快照。停用 Automation 停止新的触发订阅，已有 Run 仍可继续完成。

需要验证“事件真的进来了”时，用真实入口发送请求或等待定时事件，再根据新 Run 的来源、版本和 Trigger 数据确认。

## 检查运行

进入“运行记录 / Runs”，按状态选择 Run，结合流程视图、时间线和节点数据定位问题。

| 状态或现象 | 优先检查 |
| --- | --- |
| `QUEUED` | 同组并发上限、当前占用及替换预留。 |
| Run 为 `RUNNING`，节点在 `WAITING` | 定时等待、重试退避或结构化子执行。 |
| 节点为 `BLOCKED` | Provider、Connection、资源状态，或外部结果未知。 |
| `FAILED` / `TIMED_OUT` | 失败节点的已解析输入、Attempt 与错误记录。 |
| `CANCELLED` | 取消原因：用户操作、并发丢弃 `OVERFLOW` 或被新任务替换 `REPLACED` 等。 |
| `COMPLETED` | 关键节点的业务输出，以及外部系统自己的完成语义。 |

执行数据按分类与展示上限呈现，敏感内容可能显示受限提示。不要为排查问题而把全部业务数据改成公开数据。

“已接受”与“已完成”也要分别判断。例如 Webhook 的 `202` 表示事件和 Run 已持久化；Run 此时可能还在排队。SMTP 成功则表示邮件服务器接受提交，不代表邮件已到达收件箱。

## 取消、重试与恢复

取消会保存意图并向执行中的 Provider 传播取消信号，但不能撤销远端已经接收的操作。外部提交结果未知时，先核对服务端状态，再决定是否重新运行，避免重复副作用。

进程重启后，Scheduler 从持久记录继续处理排队、等待和取消状态；已成功节点的输出保留。安全重试取决于能力契约，不能把所有中断都当成“尚未执行”。
